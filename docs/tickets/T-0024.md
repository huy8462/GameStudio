# T-0024: thay 6 skill Three.js bằng engine-unity-*

**Mô hình khuyến nghị:** Sonnet, effort medium (viết tài liệu kỹ năng từ mã và phiếu có sẵn).

## Mục tiêu

FR-DEV-02 (sau CR-02) yêu cầu bỏ 6 skill gắn Three.js và thay bằng `engine-unity-*`. Runtime nay là Unity Web player (ADR-036, ADR-038).

## Kết quả

| Skill | Nội dung |
|---|---|
| `engine-unity-build` | Lệnh batchmode build/test, dòng `GS_BUILD`, kiểm cục bộ (`make-dev-data`, `check-local`), xuất bản poc, luật `.ps1` UTF-8 BOM, không tự push/sửa Caddyfile |
| `engine-unity-gameplay` | Khung C# (ISystem, Boot.Run, EventBus, Pool, GameClock), tất định, không cấp phát trong Tick, đa luồng, phần chưa có |
| `engine-unity-render` | URP theo tier, bảng tier, URP asset sinh bằng mã, làm ấm shader, texture KTX2, ngân sách |
| `engine-unity-perf` | `?perf=1`, trường JSON, ngưỡng, mốc A56, chẩn đoán |
| `engine-unity-qa` | QA nhẹ/đầy đủ cho player Unity, bẫy đã gặp |
